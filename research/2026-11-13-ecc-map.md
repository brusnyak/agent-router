### Five most likely build failures

1. Shadow labels are tiny: only 87 of 949 prompts labelled (8 in test, HANDOFF section 2). Fixture scores look good on noise. Mitigation: owner spot-check 50 before any gate.
2. Hook latency blows p95 < 300 ms once FTS5 + bge-small are loaded on each prompt (cold start). Mitigation: load the model once in a daemon or keep L0 rules only, measure cold and warm separately.
3. Silent-on-chit-chat rule fails: hook injects on short ambiguous prompts (dictation fragments), producing false positives. Mitigation: score floor + margin gate; fixture of 15 negatives must give <= 1 false positive.
4. Contaminated eval: query and bundle written by the same building agent (HANDOFF section 6: 0.91 number is contaminated). Three-arm result then reflects authoring bias. Mitigation: held-out test split frozen by time, bundles authored by a different worker than the one that writes queries.
5. Wiring gap: intake_hook.py is in a backup settings file only, delegation.md still claims it runs (sub-task 1 finding). A new UserPromptSubmit hook can silently collide with the orca hook or be never registered. Mitigation: verify `python3 -c` on settings.json shows the new command, and log a hook-fired line on one real prompt before calling item 2 done.
