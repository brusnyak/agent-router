# MVP "usable" definition (product-owner agent, 2026-11-13; plan by the Plan agent, caller-checked against measured data)
MVP = shadow-first UserPromptSubmit hook that returns a top-3 shortlist plus a structured prompt card, a worker hand-off via `ask`, an outcome row, and a librarian report. NOT an auto-picker (measured: dense top-1 25%, router.py top-1 28%, always-guess floor 14%, test split below floor, judges agree ~41%).

## Scope fence
- <=5 NEW modules, each <300 lines: backbone/hook.py, backbone/hook_log.py (receipt, outcome, arm, report), backbone/compile.py (dictation card), backbone/librarian.py, eval/shadow_eval.py. Reuse library.search, margin.py, outcomes.py, compose.py, understand.py, dedupe.py (apply once).
- <=1000 new non-test lines (hard cap 1200).
- NOT built: embedder/ONNX in the hook (FTS5 first), semantic-router, Oracle re-sync, Telegram inbound, UI, auto-install, auto-archive, web gather step, Rust/Go.

## Bars (dev only; test split run once)
- Routing: shortlist top-3 >= 46% on silver dev; when the gate fires, label in shown 3 at >= 60% precision with >= 25% coverage; else ship shadow only and say so.
- Prompting: compiled query beats raw by >= 5 pp top-3 AND 100% of named entities verbatim in the card; weak evidence (silver is circular), so also blind owner preference on 10 cards (8 of 10).
- Delegation: `ask --dry` gives class, tier and a gated packet for 10 of 10 hand-picked prompts; one real worker run passes the evidence gate and writes an outcome row.
- Librarian: 73 of 73 scored, deterministic across 2 runs, 44 never-invoked flagged "review", nothing moved without owner approval.

## Riskiest assumptions and cheapest tests
1. Silver labels are truth -> owner spot-check (needs context cards; the first sheet was unreviewable per owner) or discard.
2. Injection changes behaviour -> 2 weeks shadow, then 20% holdout; metric Skill-tool calls per prompt (baseline 3%).
3. 300 ms without a warm embedder -> 20 cold runs of FTS5-only hook.py, expect p95 < 300 ms.

## Demo (6 commands)
pytest -k "hook or compile or librarian"; backbone librarian --report; echo '{"prompt":...}' | hook.py; backbone ask --dry "<dictation>"; eval/shadow_eval.py --split silver; backbone router-report.
