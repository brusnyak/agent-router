## 7. RAG verdict
YES, retrieval belongs in the router, but as a shortlist generator, not a one-shot skill picker.
- `backbone/rag.py` already exists (dense + BM25 hybrid), so this is wiring and evaluation, not a new component.
- Raw-prompt to single-skill is too weak (25% top-1). Top-3 at 46% is about the level at which two judges agree with each other (~47%), so top-3 is near the label-noise ceiling.
- So: retrieve top-3 -> a cheap NIM reranker/decider picks one or none -> confidence gate -> inject. Dictation structuring and session/project context (HANDOFF plan item 4) are the likeliest accuracy gains, not a bigger embedder.
- Not proven: reranker gain on silver, silver precision (needs the spot-check), hook latency.

## 9. Research results folded in (2026-11-13 night)
Sources: `research/2026-11-13-next-steps.md` (browser worker, URLs and quotes inside, several numbers marked unverified), `research/2026-11-13-label-analysis.md` (Sonnet worker, scripts reproduced by the caller: kappa Sonnet-NIM 0.33, Sonnet-Haiku 0.38).
- Judge agreement falls with prompt length (66% under 200 chars, 33% at 600-1999, 29% at 2000+). Silver is weakest on long dictation, the case that matters. Treat silver as a dev tool, not truth.
- Query rule supported by data (lexical, silver): embed only the first 300 chars (top-3 24.6% vs 21.1% full); do not use the tail, last question, or first sentence only.
- Design to test (reported, not reproduced): index name+description only; rerank top-3 only; HyDE-style intent rewrite; P(True) confidence gate; position-swap judges; no self-judging.
- Spot-check size (formula checked by hand): n = z^2 p(1-p)/E^2 with finite correction n0/(1+(n0-1)/N); z=1.96, E=0.10, N=517 gives 82 at p=0.5 (56 at p=0.8). Protocol: `spotcheck.md` (40 items) first; `spotcheck_extra.md` (42 more) only if the owner has time; Wilson CI on the random silver items; stop trusting silver if the lower bound < 0.7.
- `eval/baseline_embed.py` now dumps `eval/heldout_v2/embed_ranks.jsonl` (top-5 cosine per real prompt) so a margin gate can be tested offline.
