Sub-task 2 verdict: best dictation-to-structured-prompt step = one local/NIM LLM call, fixed JSON schema (intent, candidate skills, hard constraints, named entities and numbers copied verbatim), instruction tuned with GEPA on labelled dictations, skill-router picks from its output, compressed via LLMLingua only if context is too big.

What to measure (prove it helps):
- Router top-1 and top-3 skill accuracy on ~50 labelled dictations: compiled vs raw dictation (A/B, promptfoo).
- Faithfulness: entity/number/negation preservation rate by string match, plus LLM-judge on 20 hand-checked samples.
- Activation: right skill fired on next run, measured by hook log (not self-report).
- Injected tokens per task and latency (NIM vs local).
- Pass rate: task outcome with compiled context vs raw; keep step only if it wins on accuracy with no faithfulness drop.
