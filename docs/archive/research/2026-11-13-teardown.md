Five design mistakes or overbuilt parts to NOT copy (both repos):
1. Agent Router size: 28 crates, 470 `.rs` files, 194,309 LOC (proven: `find crates -name '*.rs' | xargs cat | wc -l`), for a project whose README says "no established general cost or quality gain" (README.md:646, "Compared with similar projects"). Scale is not evidence. Our backbone already has 39 modules: same trap.
2. Monolith modules: `agent-router-cli/src/advisory.rs` 1,886 lines in one file, plus `MAX_*` limits at `advisory.rs:17-22`. Keep our modules under ~300 lines.
3. meta-router hook knob sprawl: `cmd/mr-hook/main.go` 731 lines, 15+ flags (`main.go:341-353`), four ranker modes, a `-ranker=rerank` that was "retired twice" (`main.go:476-479`), an unknown-flag branch (`:545-547`). Ship one ranker and one threshold in v0.
4. Speculative receipt: `internal/orch/dispatch/dispatch.go:14-95`, ~50 fields justified as "future bandit v4" (`:1-4`). Violates our Karpathy rule ("no speculative features"). Keep ~12.
5. Unqualified or churny claims: (a) "followed" hint = agreement, not effect (their own README.md:286); the 1/381 cap (CHANGELOG.md:44) was chosen on that number. (b) `cmd/mr-outcomes/main.go:97-106` ships a window report that its own note says "reads HIGH when sessions run concurrently". (c) The B12 ratchet in `docs/complexity-budget.json` grew from ~25k to 32,503 Go LOC in months, each step a long narrative (`max_go_loc` field, proven). (d) freelane comment claims a 0600 credential file (`token.go:17,32`), but nothing checks the mode (grep). Their evidence habit is good (measured, dated, live captures); copy the habit, not the volume.

Good habits to copy (not overbuilt): honest status table with "remaining limit" column (README.md:136-150); "UNKNOWN stays unknown" in the decision diagram (README.md:457); B15 "a hole is never evidence" (ROUTER_BIBLE.md:82-84).
